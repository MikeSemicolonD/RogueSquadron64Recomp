# Rogue Squadron 64 Recompiled wiki

How to mod with the [RS64 Explorer](https://mikesemicolond.github.io/RogueSquadron64Recomp/tools/web/rs64-explorer/).

> [!IMPORTANT]
> Very unfinished and very much a work in progress.
>
> **I don't recommend using it to make mods currently as things could change.**
>
> The explorer works, but some features are missing or incomplete.
>
> User Experience is still **very very** rough.
>
> Docs are still being actively updated and changed. This notice will be removed once I'm confident in the tool usage/robustness.
