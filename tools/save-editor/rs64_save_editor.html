Pilot accounts

Three save slots. Toggle a slot active to include it; the selected slot is the one the game loads first. Click a level tile to cycle its medal: none → bronze → silver → gold.

Names are 3 arcade-style initials (stored as 3 bytes plus a null terminator). Medal slots cover 19 level entries. “Current level” is the highest reached (0–16). Weapon upgrades are the per-pilot unlock word (account +0x0C).

Elite Rogues (high scores)

The ten-entry high-score board. Score = golds×4 + silvers×2 + bronzes×1; every 4 points raises the rank shown on the in-game board.

#NameLevel BronzeSilverGold AcctScoreRank

Bronze / silver / gold are counts (0–31) packed into a 16-bit field, not per-level medals.

Options

Global options stored in the save body. Volumes are raw byte values as the game stores them.

The active-slot mask has one bit per pilot slot (bit0=slot1…). Editing pilot toggles on the Pilots tab updates it for you.

Ships, bonus levels & cheats

These are the game's cheat-code unlocks, stored in the save (cheatCodeFlags, body +0x08). Ticking a box sets the same flag the cheat screen would. Shared across all pilots.

Raw EEPROM bytes

512-byte image. Poke any byte directly, then recompute checksums so the game accepts the file. Structured edits on the other tabs already keep both copies mirrored and checksummed. This is the exact format the recompilation stores at saves/<game-id>.bin — load that file to edit your progress, then drop the exported copy back in with the game closed.
