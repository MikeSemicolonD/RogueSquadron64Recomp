Features

Widescreen & HD

Any resolution with widescreen. Using frame interpolation to match your monitor's refresh rate.

Draw distance

Up to 2.5x the draw distance.

Controls

Mouse, gamepad, H.O.T.A.S. or touch controls via virtual buttons/joystick.

Platforms

Windows, Linux, MacOS and Android.

Ray tracing Experimental

Laser light, real shadows and reflections, sunbeams through the fog.

Multiplayer Co-op Experimental

Online co-op. Same mission, shared victory.

Web tools

RS64 Explorer

Browse the ROM's models, levels, cutscenes, audio and fonts in the browser, and build mods from them.

Save Editor

Open a recomp save or cart EEPROM dump, edit pilots, medals and unlocks, and export it back.
